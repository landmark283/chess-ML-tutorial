## 回顾测验（L01，3 题，不拦路）

### 第 1 题：`[[0]*3]*3` 和 `[[0]*3 for _ in range(3)]`

区别：

```
[[0]*3]*3 这里的第二个*3复制的是引用，而[[0]*3 for _ in range(3)]是执行 [0]*3 3次，得到的是3个不同的东西。
```

**这个区别在搜索里为什么致命？**

```
[[0]*3]*3 实际上只创建了容纳了3个元素的表，根本装不下9个格子。后续搜索时会反复修改格子的值，导致错误。
比如a=[[0]*3]*3
a[0][1] = 1
a[1][1] = 0 # 这里a[0][1]也变成了0， a[0][1] = 1保存的信息丢失了。
```
