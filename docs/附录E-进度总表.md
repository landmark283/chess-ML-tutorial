## 阶段 A｜先造出一个会下棋的程序

### L01 把棋变成程序：棋盘、规则与测试　`5–6h`

- [ ] **K1.2** 棋盘的数据表示 —— 一维 vs 二维、坐标约定、两种摊平写法
- [ ] **K1.3** 可变性与深拷贝陷阱 —— `[[0]*3]*3`、`is` vs `==`、浅/深拷贝
- [ ] **K1.4** 规则引擎 —— 合法走法、胜负判定（横竖斜）、平局、判断顺序
- [ ] **K1.5** 为什么先写测试 —— `assert`、测试运行器、怎么选测试

- [ ] 🚪 **出关测验**：找出 `buggy.py` 的 3 个 bug
- [ ] 🎯 **课末实操**：命令行双人对下 + `python run_tests.py` 全绿
- 🏆 **产出**：可人工对下的井字棋 + 31 个通过的测试

### L02 搜索：minimax → negamax → alpha-beta　`6–8h`

- [ ] **K2.1** 博弈树与递归 —— 把下棋变成"在树上选一条路"
- [ ] **K2.2** minimax —— 我方 max、对方 min
- [ ] **K2.3** negamax —— `value = max(-value(child))`，为什么能省一半代码
- [ ] **K2.4** alpha-beta 剪枝 —— α / β 的含义、**为什么剪掉的分支不影响结果**
- [ ] **K2.5** 分支因子与深度爆炸 —— `b^d`，五子棋为什么不行
- [ ] **K2.6** 限深搜索与手工评估 —— 地平线效应初现

- [ ] 🚪 **出关测验**（核心题）：*"alpha-beta 剪掉的分支里，会不会藏着更好的走法？为什么不会？"*
- [ ] 🎯 **课末实操**：AI 对战随机对手 1000 局零败 + 剪枝前后节点数对比表
- 🏆 **产出**：永不落败的井字棋 AI + 剪枝数据表
- 💡 **课末感受**（预期）：*"评估函数权重全靠拍脑袋，再也调不动了。"* → L03 的理由

## 阶段 B｜传统机器学习核心

### L03 让机器自己找规则：回归与梯度下降　`6–8h`

- [ ] **K3.1** 机器学习的三个问题 —— 表示 / 目标 / 优化
- [ ] **K3.2** 评估函数就是值函数近似 —— 把手工评估写成 `w·x`
- [ ] **K3.3** 线性回归与最小二乘 —— 模型形式、损失函数、为什么用平方误差
- [ ] **K3.4** 梯度下降 —— 梯度、学习率的双刃剑、手写 vs `sklearn`
- [ ] **K3.5** 训练/测试划分与过拟合
- [ ] **K3.6** 学井字棋评估函数的权重 —— 特征 → 标签 → 权重流水线

- [ ] 🚪 **出关测验**：给一条"训练误差低、测试误差高"的曲线，诊断 + 3 个处方

### L04 从数值到概率：逻辑回归与分类评估　`6–8h`

- [ ] **K4.1** 为什么不能直接回归 0/1 —— 输出越界、平方损失不合适
- [ ] **K4.2** sigmoid 与对数几率 —— 把实数压到 (0,1)
- [ ] **K4.3** 交叉熵损失 —— 为什么不用平方误差
- [ ] **K4.4** 混淆矩阵与四个指标 —— 准确率/精确率/召回率/F1，**各自在什么场景骗人**
- [ ] **K4.5** 类别不平衡与阈值 —— 不能只看准确率
- [ ] **K4.6** 概率校准 —— 校准曲线、Brier score、**跨搜索深度可比性**

- [ ] 🚪 **出关测验**：给"疾病检测准确率 99%"的场景，指出错在哪、该换什么指标
- [ ] 🎯 **课末实操**：鸢尾花二分类 > 95%；胜率模型接回井字棋；画校准曲线
- 🏆 **产出**：输出"我赢的概率"的评估函数 + 校准曲线
- 🔗 **伏笔回收点**：L08 静态搜索会再次用到"跨深度可比"
