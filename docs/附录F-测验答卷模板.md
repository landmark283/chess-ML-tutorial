## 答题的三条原则

**① 写"我怎么想的"，不只写结论。**

我不需要标准答案 —— 我需要知道你的思路在哪一步拐错了弯。
比如：

> ❌ 差：`LINES` 里漏了 `(2,4,6)`。
> ✅ 好：我以为是 `winner` 的判断逻辑错了，因为它对横竖都对、只有斜的错。后来发现判定逻辑只有一个循环，所以问题一定在**数据**里 —— 去数 `LINES` 有几条，数出 7 条，才发现少了一条。

**② 不确定就写"我不确定"。**

"我不确定"是最有价值的一句话 —— 它直接告诉我该重讲哪里。猜一个看起来对的答案反而会掩盖问题。

**③ 代码题贴代码，报错题贴原文。**

不要转述报错信息（"它说什么类型不对"）。**原文里有行号和位置**，那是关键线索。

## 交卷与批改流程

```
你：写完 notes/测验-LNN.md
  ↓
你：「LNN 答完了」（或者直接把某一段贴进对话）
  ↓
我：逐题批改
    · 对 → 说明你对在哪个关键点上（不只是"对"）
    · 错 → 指出**你的思路在哪一步偏了**，而不只是给正确答案
    · 半对 → 拆开看是哪半个概念没通
  ↓
结果分三种：
    ✅ 全部通过 → 进下一课
    🟡 个别知识点要补 → 我重写那一节 + 换例子，然后你补测（只补那一节）
    🔴 大面积不过 → 说明缺前置，我们一起往回找是哪一课漏了
```

**允许无限次补考，不允许跳过。**
补考不是"重做一遍卷子" —— 我会换一道题、换一个角度，确保你是真会了而不是背下了答案。

## 关于"我答不出来"这件事

**答不出来完全正常，而且很有用。** 它精确地指出了教程的哪个地方没写清楚。

遇到这种情况，你有三种选择：

| 说法 | 我做什么 |
|---|---|
| 「这题我不懂」 | 我把对应的知识点**重写成更细的版本**（可能换例子、加图解） |
| 「这里慢一点」 | 我把这一课拆成两次学，或者补一个过渡小节 |
| 「这个跳过」 | 我标上"跳过"，但**记在案**：后面用到它的地方我会提醒你回来 |

**唯一没用的一句话是"嗯，大概懂了"。** 真的懂了的表现是你能用自己的话讲一遍、能写出代码、能指出别人的错。这三样我都测。
